# Implementation plan

1. Scaffold and document architecture.
2. Add schema, RLS, transactional operations and development seed.
3. Add server authorization, validation, private storage and APIs.
4. Build storefront, gallery, custom form, cart and guest receipt.
5. Build token-based quote decisions and proof submission.
6. Build admin operations, calendar, reporting and resource editors.
7. Add important unit/browser/database checks and run verification.

Live database verification requires configured Supabase and an admin test user. Deployment requires real product photos, business contact/payment settings and delivery policies.
